# One recommended font: IBM Plex Mono

Type is half of how an app looks, so Inglenook recommends one font and every port's install guide sets it where the app allows.

The font is **IBM Plex Mono**. It is monospaced, calm and slightly humanist, readable at small sizes, and free under the SIL Open Font License. Where an app shows icons (shell prompts, file trees, status lines), use **BlexMono Nerd Font**, the Nerd Fonts build of IBM Plex Mono with icons added, in its Mono version so every icon is one cell wide.

## Consequences

- Every port README has a **Set the font** section. Apps that cannot change their font say so.
- The font is a recommendation, not a requirement: a port still works with any monospaced font.
- The preview site uses IBM Plex Sans, Serif, and Mono.
