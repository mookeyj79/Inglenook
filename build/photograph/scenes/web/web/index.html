Moss, a shade softer

Day's moss moved from 0.52 to 0.5 lightness. Every port was rebuilt from the palette, and the checks caught the one that drifted.

  • palette
  • moss
  • build

Run pwsh build/check.ps1 after any palette change. The drift check compares each port's dist/ with a fresh build, so a port nobody rebuilt fails the check before it reaches main.

# Rebuild every port that uses moss
[CmdletBinding()]
param([string]$Palette = 'palette/palette.json')
- $moss.l = 0.52
+ $moss.l = 0.5
if ($moss.l -lt 0.45) { throw 'Too dark' }
Import-Module ./build/lib/Build.psm1
Update-Port -All -Palette $Palette -Force:$true

Heads up: a palette change rebuilds every port, so commit the new dist/ files with it.
